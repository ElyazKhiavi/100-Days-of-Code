# 📗 Day 5 — Python Loops

> [!IMPORTANT] Core Concepts
>
> - **`for` loops** — iterate over lists, strings, ranges; repeat code blocks
> - **`range()`** — generate number sequences: `range(stop)`, `range(start, stop)`, `range(start, stop, step)`
> - **`random.shuffle()`** — randomize list order in-place; random.shuffle doesn't return a new shuffled list.
> - **`"".join()`** — join all items in a list into a single string, using the string before it as separator; avoids writing a loop for the result
> - **Built-in functions:** `sum()`, `max()`, `min()` — work on iterables
> - **Loop + conditionals** — recreate built-in functions manually (great learning exercise)
> - **Password Generator** — combining lists, loops, `random.choice()`, `shuffle()`, and input validation

## Syntax / Key Commands

### For Loops

```python
# Iterate over a list directly
fruits = ["Apple", "Orange", "Grape"]
for fruit in fruits:
    print(fruit)       # each item, one by one

# Iterate with range(n) → 0 to n-1
for i in range(5):
    print(i)           # 0, 1, 2, 3, 4

# Iterate over a string
for char in "Hello":
    print(char)        # H, e, l, l, o
```

### The `range()` Function

Python's way of generating number sequences on the fly.

| Call              | Produces         | Notes                         |
| ----------------- | ---------------- | ----------------------------- |
| `range(5)`        | 0, 1, 2, 3, 4    | Start at 0, stop **before** 5 |
| `range(2, 8)`     | 2, 3, 4, 5, 6, 7 | Start at 2, stop **before** 8 |
| `range(0, 21, 2)` | 0, 2, 4, ..., 20 | Step by 2 (even numbers)      |

**Key rule:** The stop value is **never included**. If you want it, use `stop + 1`.

```python
# Count 1 to 100 (inclusive)
for num in range(101):
    print(num)

# Even numbers 0-20
for i in range(0, 21, 2):
    print(i)

# Sum 1 to 100 (Gauss would be jealous)
total = 0
for num in range(101):
    total += num
print(total)  # 5050
```

### Built-in Functions on Lists

```python
scores = [100, 171, 98, 134, 189, 130, 199]

sum(scores)    # 1021 — add all items
max(scores)    # 199 — largest value
min(scores)    # 98 — smallest value
len(scores)    # 7 — count of items
```

### Recreating `max()` and `min()` with Loops

Understanding how built-ins work under the hood:

```python
scores = [100, 171, 98, 134, 189, 130, 199]

# Manual max()
hold = scores[0]          # start with first item
for score in scores:
    if score > hold:
        hold = score      # found a new maximum
print(hold)               # 199 ✓

# Manual min() (reuse hold — it's already 199)
for score in scores:
    if score < hold:
        hold = score      # found a new minimum
print(hold)               # 98 ✓
```

### Random Shuffle

```python
import random
fruits = ["Apple", "Orange", "Grape"]
random.shuffle(fruits)     # shuffles IN-PLACE (returns None!)
print(fruits)              # order randomized
```

5. Join into final password string

## ⚠️ Watch Out / Pitfalls

| Mistake                                 | Why It Breaks                                       | Fix                                              |
| --------------------------------------- | --------------------------------------------------- | ------------------------------------------------ |
| `for i in range(5)` prints 0–4, not 1–5 | `range(stop)` starts at 0, stops **before** stop    | Use `range(1, 6)` for 1–5, or `range(1, stop+1)` |
| Forgetting indent under `for:`          | **IndentationError** — expected an indented block   | Indent loop body (4 spaces or Tab)               |
| Mixing tabs and spaces                  | Weird **IndentationError**s or silent bugs          | Pick one style and stick to it (PEP 8: 4 spaces) |
| `random.shuffle()` returns `None`       | It shuffles **in-place**! Don't do `x = shuffle(y)` | Just call `shuffle(list)` then use `list`        |
| Off-by-one in `range()`                 | Classic bug — always one item missing/included      | Remember: stop value is **exclusive**            |
| Empty loop body (`pass` forgotten)      | **IndentationError** or syntax error                | Add `pass` if body intentionally empty           |
