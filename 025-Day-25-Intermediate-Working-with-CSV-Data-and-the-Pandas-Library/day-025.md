# 📗 Day 25 — Working with CSV Data and the Pandas Library

> [!IMPORTANT]
>
> - **The `csv` Module** — Python's built-in module for parsing CSV files into lists of strings.
> - **Pandas Library** — The industry standard for data analysis. Converts CSVs into DataFrames (2D tables) and Series (1D rows/columns).
> - **Data Selection** — Pandas converts column headers into object attributes (e.g., `data.temp` instead of `data["temp"]`).
> - **Conditional Row Selection** — Filtering rows based on column values: `data[data.day == "Monday"]`.
> - **PIL (Pillow)** — Python Imaging Library. Used here to resize a GIF to match the Turtle screen dimensions.

---

## Syntax / Key Commands

### Reading CSVs (Built-in vs Pandas)
```python
import csv
# Built-in: Returns lists of strings
with open("data.csv", "r") as f:
    data = csv.reader(f)

import pandas as pd
# Pandas: Returns a DataFrame
data = pd.read_csv("data.csv")
```

### Pandas DataFrame & Series Operations
```python
# Creating a DataFrame from a dictionary
df = pd.DataFrame({"students": ["Alice", "Bob"], "scores": [85, 92]})

# Extracting a Series (Column)
temps = data["temp"].to_list()

# Pandas math methods
average = data["temp"].mean()
max_temp = data["temp"].max()

# Conditional Row Selection (Get the row where temp is max)
monday = data[data.day == "Monday"]
max_temp_row = data[data.temp == data.temp.max()]

# Extracting a pure scalar value from a Series (avoids index notation issues)
x_cor = data[data.state == "Texas"].x.item()
```

### Exporting to CSV
```python
df.to_csv("new_data.csv")
```

### Resizing Images with PIL
```python
from PIL import Image
img = Image.open('blank_states_img.gif')
img = img.resize((2175, 1473))  # Scale to fit Turtle screen
img.save('big_blank_states_img.gif')
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `KeyError` in Pandas | Misspelling a column header or case mismatch | Pandas is case-sensitive. Print `data.columns` to check exact names. |
| Extracting a value returns a Series, not an int | `data[data.state=="TX"].x` returns a Series | Use `.item()` to extract the raw scalar value |
| Turtle image doesn't fit screen | The default GIF resolution is too small for large screens | Use `PIL.Image.resize()` to scale the image before adding it as a Turtle shape |
| Manually parsing CSV is a nightmare | Newlines, commas inside strings, etc. | Stop using `open()` and `.split()`. Use `csv` or `pandas` |
