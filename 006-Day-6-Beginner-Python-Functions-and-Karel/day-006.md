## Syntax / Key Commands

### Defining and Calling Functions

```python
# Basic function definition
def my_function():
    print("Running the Function")

my_function()  # → "Running the Function"

# Function with parameter
def repeat_message(n):
    for _ in range(n):
        print("Hello!")

repeat_message(3)  # prints 3 times
```

**Key rules:**

- Use `def` keyword + function name + `()` + `:`
- Function body must be **indented**
- Function must be **called** to execute (definition alone does nothing)
- Parameters go inside the parentheses

### Useful Built-in Functions Reference

| Function                      | What It Does                   | Example                      |
| ----------------------------- | ------------------------------ | ---------------------------- |
| `len()`                       | Returns length of sequence     | `len("hello")` → 5           |
| `print()`                     | Output to console              | `print("Hi")`                |
| `input()`                     | Get user input (returns str)   | `input("Name? ")`            |
| `int()` / `float()` / `str()` | Type conversion                | `int("42")` → 42             |
| `min()` / `max()`             | Smallest / largest in iterable | `min([3,1,2])` → 1           |
| `sum()`                       | Add all numbers in iterable    | `sum([1,2,3])` → 6           |
| `type()`                      | Check data type                | `type(42)` → `<class 'int'>` |

Full list: [docs.python.org/3/library/functions.html](https://docs.python.org/3/library/functions.html)

### While Loops

```python
# Basic while loop
i = 1
while i < 6:
    print(i)
    i += 1        # don't forget to increment!
# Output: 1 2 3 4 5

# while with break
i = 1
while i < 6:
    if i == 3:
        break     # exit loop immediately
    print(i)
    i += 1
# Output: 1 2

# while with continue
i = 0
while i < 6:
    i += 1
    if i == 3:
        continue  # skip rest of this iteration
    print(i)
# Output: 1 2 4 5 6

# while...else (else runs when condition becomes False)
i = 1
while i < 6:
    print(i)
    i += 1
else:
    print("Loop finished naturally")
# NOTE: else is NOT executed if loop was stopped by break!
```

**⚠️ Infinite Loop Warning:** If you forget to update the condition variable inside the loop, it runs forever. `Ctrl+C` to kill.

### Indentation Notes

- Python uses **indentation** (not `{}` like JS) to define code blocks
- Most IDEs auto-indent or highlight errors in red
- **Shortcuts:** `Ctrl+]` indent, `Ctrl+[` unindent (VS Code / VScodium)
- **Tabs vs Spaces:** Use **tabs** — they're on the keyboard for a reason. 4 spaces per indent is inefficient to type.

#### The Maze ⭐ (Final Challenge)

> 📂 [The-Maze.py](day-6-projects/reeborgs-world/the_maze.py)

Navigate a maze using only: `move()`, `turn_left()`, `turn_right()`, and conditionals.

**My solution — Wall-Hugging Algorithm:**

```python
def turn_right():
    turn_left()
    turn_left()
    turn_left()

# Phase 1: Deliver robot to a position with wall on right
while not wall_on_right():
    turn_left()
    if not wall_in_front():
        move()

# Phase 2: Follow right wall until goal
while not at_goal():
    if right_is_clear():
        turn_right()
        move()
    elif front_is_clear():
        move()
    else:
        turn_left()
```

**The Edge Case Bug:** In certain starting positions, the robot enters an **infinite loop** because it circles around an open area without ever finding a right wall to hug.

**Fix:** Added Phase 1 — a pre-loop that moves the robot forward until it finds a wall on its right side. Only then does the main wall-hugging logic begin.

**Angela's solution (slightly shorter):**

```python
while front_is_clear():
    move()       # just move forward until hitting a wall
while not at_goal():
    # ... same wall-hugging logic
```

Both approaches valid — there's no single correct solution. Mine is more explicit about _why_ it works.

#### Simple Banking System 🏦 (Bonus Practice)

## ⚠️ Watch Out / Pitfalls

| Mistake                         | Why It Breaks                                      | Fix                                             |
| ------------------------------- | -------------------------------------------------- | ----------------------------------------------- |
| Forgetting to call the function | Definition alone does nothing                      | Always add `function_name()` after defining     |
| Infinite `while` loop           | Condition never becomes False                      | Ensure loop body updates the condition variable |
| `while...else` after `break`    | `else` block skipped if loop broke                 | `else` only runs on natural condition failure   |
| Mixing tabs and spaces          | Weird **IndentationError**s or silent misalignment | Pick ONE style (tabs!) and stick to it          |
| Off-by-one in Reeborg logic     | Robot turns wrong way or gets stuck                | Trace through step-by-step on paper first       |
| Edge cases in algorithms        | Works for main path but fails in corner cases      | **Test thoroughly** — the maze taught me this   |
