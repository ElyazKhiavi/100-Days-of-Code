# 📗 Day 16 — Object Oriented Programming (OOP)

> [!IMPORTANT] Core Concepts
>
> - **Procedural vs OOP** — Moving away from top-to-bottom scripting towards modeling real-world objects.
> - **Classes & Objects** — A class is the blueprint (e.g., `Animal`); an object is the instance (e.g., `Dog`).
> - **PascalCase** — Convention for naming classes (`MyClass`, not `myClass`).
> - **Attributes & Methods** — Variables (has) and functions (does) tied to an object.
> - **`pip` & PyPI** — Installing external packages like `prettytable`.

---

## Syntax / Key Commands

### Creating a Class and Object

```python
# PascalCase for classes
class Animal:
    def __init__(self):
        self.name = "Dog"  # Attribute

    def speak(self):       # Method
        print("Bark!")

my_pet = Animal()  # Creating an object
my_pet.speak()
```

### Installing & Using External Packages

```bash
pip install prettytable
```

```python
from prettytable import PrettyTable
table = PrettyTable()
table.field_names = ["Name", "Type"]
table.add_row(["Pikachu", "Electric"])
print(table)
```

### Turtle Graphics (Built-in)

```python
from turtle import Turtle, Screen
tim = Turtle()
tim.shape("turtle")
tim.color("DodgerBlue4")
tim.forward(100)
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| Forgetting `self` | Defining a method without passing the instance | Always make `self` the first parameter: `def method(self):` |
| Class names in camelCase | Using `myClass` instead of `MyClass` | Use `PascalCase` (every word capitalized) |
| Modifying global state | Changing variables outside the object | Keep state inside the object via `self.attribute` |
