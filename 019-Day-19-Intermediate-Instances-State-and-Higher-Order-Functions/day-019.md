# 📗 Day 19 — Instances, State and Higher Order Functions

> [!IMPORTANT] Core Concepts
>
> - **Multiple Instances** — Creating multiple independent objects from the same class, each with its own state.
> - **Event Listeners** — Using `screen.onkey()` to bind keyboard inputs to functions.
> - **Callbacks & Parentheses** — `onkey` requires a function reference, not a call. You can't pass arguments with parentheses.
> - **Lambda Functions** — Anonymous, one-line functions used to bypass the parentheses rule when passing arguments to callbacks.
> - **Higher-Order Functions** — Functions that accept other functions as arguments.

---

## Syntax / Key Commands

### Event Listeners & The Lambda Rule
When passing a function to `onkey`, you can't use `move(0)` because it executes immediately. Use `lambda` to pass arguments cleanly.
```python
from turtle import Screen

sc = Screen()
sc.listen()

# Bad: sc.onkey(move(0), "Right")  # Executes immediately!
# Good: Using lambda to pass the argument
sc.onkey(fun=lambda: move(0), key="Right")
```

### Alternative: Closures
```python
def bind(key, direction):
    def callback():
        move(direction)
    sc.onkey(fun=callback, key=key)
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `onkey` function executes immediately | Passing a function call `move()` instead of the reference | Use `move` or wrap it in `lambda: move()` |
| Turtle states mix up | Using global variables to track positions | Store state inside the object instance |
| Screen not listening | Forgetting to call the listener | Use `screen.listen()` before `onkey()` |
