# Day 38 — Workout Tracking Using Google Sheets

## Core Concepts
- **`strftime` format codes** — `%Y-%m-%d %H:%M:%S` for date/time fields; `%H` is 24-hour, `%I` is 12-hour.
- **`any()` vs `all()`** — required-credential validation uses `if not all([...])`; `any()` passes when even one variable is set.
- **Sheety API contract** — POST payloads are wrapped under the sheet name key (`{"workout": {...}}`); auth via `Authorization` header.
- **Nutritionix natural-language exercise endpoint** — free-text query in, structured `duration_min` / `nf_calories` out; auth via `x-app-id` / `x-app-key` headers. Served through the course proxy (`app.100daysofpython.dev`).
- **`.env.example`** — committed with variable names, links, and empty values; the real `.env` stays gitignored.

## Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| Validating multiple required vars with `any()` | Reads naturally as "are my credentials set?" | `if not all([...])` — fails when even one is missing |
| Unwrapped Sheety payload | Assuming a flat JSON body | Wrap row fields under the sheet name key |
| `Authorization` header without scheme | Storing a bare token | Include `Bearer <token>` (or `Basic <b64>`) in the header value |
| `json()["exercises"][0]` unguarded | Assuming at least one match | Check the list length before indexing |
| Committing `.env` | Quick setup convenience | Gitignore `.env`, ship `.env.example` |
