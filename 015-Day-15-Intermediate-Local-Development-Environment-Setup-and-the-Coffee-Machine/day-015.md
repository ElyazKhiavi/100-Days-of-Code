## 🛠️ Projects

### The Coffee Machine ☕ (First Intermediate Project)
> 📂 [**View source (Polished) →**](The-Coffee-Machine/The-Coffee-Machine-Polished.py)
> 📂 [**View flowchart →**](The-Coffee-Machine/The-Coffee-Machine-Flowchart.svg)

A terminal-based simulation of a coffee machine. Handles resource deduction, coin validation, and change calculation.

**Core Logic Flow:**
1. Print menu, get user input.
2. Check hidden commands (`off` to quit, `report` to see status).
3. Check if resources are sufficient for the selected drink.
4. Process coin transaction (validate input, sum coins, compare to cost).
5. If successful: deduct resources, add money, dispense coffee.

**Features:**
- `try/except` block to ensure coin inputs are valid, non-negative integers.
- `round(..., 2)` to handle floating-point precision issues with currency.
- Polished version includes docstrings, constants for coin values, and separated `get_coin_input()` function for DRY code.

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| Floating point errors | `2.5 - 1.1` might equal `1.4000000000000001` | Always use `round(value, 2)` when dealing with currency |
| Negative coin inputs | User types `-5` for quarters, breaking the math | Check `if count < 0:` and reject, or use `abs()` |
| Modifying global state incorrectly | Forgetting to subtract materials after a successful transaction | Ensure `make_coffee()` is only called after `check_resources()` and `transaction()` pass |
