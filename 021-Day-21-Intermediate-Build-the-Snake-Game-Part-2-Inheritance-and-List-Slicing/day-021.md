# 📗 Day 21 — Build the Snake Game Part 2

> [!IMPORTANT] Core Concepts
>
> - **Class Inheritance** — Creating a new class that inherits attributes and methods from an existing class (e.g., `class Fish(Animal):`).
> - **The `super()` Function** — Calling the parent class's `__init__` or methods to ensure the parent is set up correctly.
> - **List Slicing** — Extracting parts of a list using `[start:stop:step]`. Used heavily for tail collision detection.
> - **Collision Detection** — Using `.distance()` and coordinate checks to trigger game events (eat food, hit wall, hit tail).

---

## Syntax / Key Commands

### Inheritance & `super()`
```python
class Fish(Animal):
    def __init__(self, name):
        super().__init__(name)  # Passes 'name' to Animal's init

    def breath(self):
        super().breath()        # Calls Animal's breath method
        print("Underwater.")
```

### List Slicing
```python
my_list = [1, 2, 3, 4, 5, 6]

my_list[::2]    # [1, 3, 5] (every other item)
my_list[::-1]   # [6, 5, 4, 3, 2, 1] (reverses the list)

# Used in Snake Game to skip the head and check tail collision:
for segment in snake.segments[1:]: 
    if snake.head.distance(segment) < 20:
        game_over = True
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `AttributeError` in child class | Forgetting to call `super().__init__()` | Always call `super().__init__()` in the child's `__init__` |
| Snake dies immediately | Tail collision loop includes the head | Use slicing `snake.segments[1:]` to skip the head |
| Food spawns off-grid | Random coordinates aren't multiples of move distance | Generate random numbers and force them to be divisible by the move range |
| Score text overlaps | `write()` draws over the previous text | Call `self.clear()` before writing the new score |
