# 📗 Day 22 — Build Pong The Famous Arcade Game

> [!IMPORTANT]
>
> - **OOP Architecture** — Splitting the game into independent modules: `Divider`, `Paddle`, `TheBall`, `Scoreboard`.
> - **Collision Detection** — Using `.distance()` and coordinate checks to bounce the ball off walls and paddles.
> - **Game State Management** — Using an outer loop (`while not game_over`) and an inner loop (`while not match_over`) to handle points vs. the whole match.
> - **Inheritance** — All game objects inherit from `turtle.Turtle`. Must call `super().__init__()`.

### Ball Collision & Speed Increase

```python
def check_paddle_collision(self, r_paddle, l_paddle):
    if self.distance(r_paddle) < 80 and self.xcor() > 0:
        self.x_pace = -abs(self.x_pace)  # Force leftward movement
        self.x_pace *= 1.1               # Increase speed by 10%
```

### The Pong Game 🏓 (Main Project)

> 📂 [**View source (Polished) →**](the-pong-game-polished/main.py)
> 📂 [**View flowchart →**](the-pong-game/assets/pong-game-architecture-flowchart.svg)

A 2-player Pong game played to 3 points.

**Architecture:**

- `main.py`: Sets up screen, creates objects, runs the match/game loops.
- `paddles.py`: `Paddle` class. Uses simple `if new_y > MAX_Y: return` for boundaries.
- `the_ball.py`: `TheBall` class. Handles movement, top/bottom bouncing, and paddle collision. Speeds up by 10% on each hit.
- `scoreboard.py`: `Scoreboard` class. Tracks points and displays game-over text.
- `divider.py`: `Divider` class. Draws a centered dashed line.

> [!note]
> The original code (`the-pong-game/`) had issues with the divider centering, confusing paddle boundary checks, and a collision threshold that was too large (180 vs 80). The polished version (`the-pong-game-polished/`) includes these fixes, documented in `docs/pong-problems-and-fixes.md`.

## ⚠️ Watch Out / Pitfalls

| Mistake                       | Why It Happens                                                     | Fix                                                                    |
| ----------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| Score doesn't update visually | `screen.update()` isn't called immediately after writing the score | Call `screen.update()` right after `scoreboard.update_score()`         |
| Ball bounces from far away    | `.distance()` threshold is too large (e.g., 180)                   | Use a smaller threshold based on paddle width + ball radius (e.g., 80) |
| Paddle goes off screen        | Boundary check logic is fragile                                    | Use simple coordinate checks: `if new_y > MAX_Y: return`               |
| Divider line isn't centered   | Hardcoded forward distances don't match screen size                | Calculate from `screen_height // 2` and loop upwards                   |
