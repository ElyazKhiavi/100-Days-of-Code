# 📗 Day 23 — The Turtle Crossing Capstone Project

> [!IMPORTANT] Core Concepts
>
> - **Capstone Consolidation** — Combining OOP, Turtle graphics, collision detection, and game loops into one project.
> - **`random.randrange()`** — Like `range()`, but picks a random number. Useful for spawning objects on a grid (`randrange(start, stop, step)`).

### Grid-Aligned Random Spawning
`randint` picks any number. `randrange` allows a step, keeping objects aligned.
```python
import random

# Picks a random y-coordinate: -780, -670, -560, etc.
y_pos = random.randrange(-780, 870, 110) 
```

## 🛠️ Projects

### Turtle Crossing 🐢 (Capstone Project)
> 📂 [**View source (Polished) →**](turtle-crossing-polished-version/main.py)

A Frogger-style game where the player navigates a turtle through moving cars to reach the top.

**Architecture:**
- `main.py`: Game loop, screen setup, key binding, collision checking.
- `player.py`: `Player` class. Moves up, checks for win, returns to start.
- `car_manager.py`: `Car` and `CarManager` classes. Spawns cars, moves them, re-spawns them off-screen, handles speed scaling.
- `scoreboard.py`: Tracks level, displays game over.
- `finish_line.py`: Draws a checkered finish line using nested loops.

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| Impossible to win | Too many cars spawning, blocking all paths | Limit the number of cars and use `randrange` to ensure gaps |
| Cars spawn on top of each other | Random X and Y overlap | Spread out spawn coordinates or check distance before spawning |
| Cars leave a trail | `tracer(0)` is on, but pen isn't up | Call `.penup()` in the `Car` `__init__` |
| Difficulty doesn't increase | Only updating one car's speed | Iterate through the whole `self.cars` list to update speed |
