# 📗 Day 9 — Dictionaries, Nesting & Secret Auction

> [!IMPORTANT] Core Concepts
>
> - **Dictionaries** — Unordered key-value pairs. Accessed via keys (strings/ints), not indices.
> - **Nesting** — Placing lists inside dicts, or dicts inside dicts. Allows modeling complex real-world data.
> - **Dictionary Methods** — `.keys()`, `.values()`, `.items()`, `.get()`, `.pop()`, `.update()`.
> - **Iteration** — `for key in dict:` iterates over keys by default. Use `.items()` to get both.
> - **Elegant Max/Min** — `max(dict, key=dict.get)` returns the key with the highest value.

---

## Syntax / Key Commands

### Basic Dictionary Operations

```python
# Definition & Access
my_dict = {"name": "Dante", "age": 25}
print(my_dict["name"])  # "Dante"

# Adding / Updating
my_dict["location"] = "NYC"  # Adds new key
my_dict["age"] = 26          # Updates existing key

# Safe Access (avoids KeyError)
print(my_dict.get("score", 0))  # 0
```

### Nesting Structures

```python
# Dict of Dicts
movies = {
    "Fight Club": {
        "year": 1999,
        "director": "David Fincher"
    }
}
print(movies["Fight Club"]["year"])  # 1999

# Dict with List values
character = {
    "Name": "Luffy",
    "Personality": ["Confident", "Loyal", "Fearless"]
}
print(character["Personality"][0])  # "Confident"
```

### Iterating & Finding Max Value

```python
scores = {"Alice": 92, "Bob": 85, "Charlie": 95}

# Iterate key-value pairs
for name, score in scores.items():
    print(f"{name}: {score}")

# Find key with highest value
winner = max(scores, key=scores.get)  # "Charlie"
```

Blind auction system where users input names and bids. Terminal is cleared between bidders so no one sees previous bids.

**Core Logic:**

```python
def submit_action(bidders):
    user_name = input("What is your name? ")
    user_bid = int(input("How much is your bid? $"))
    bidders[user_name] = user_bid  # Add to dict

def auction_winner(bidders):
    # Elegant max value lookup
    winner = max(bidders, key=bidders.get)
    print(f"Winner is {winner} with ${bidders[winner]}!")
```

**Features:** `os.system("clear")` for terminal privacy, input validation for numeric bids, replay loop for auctioning multiple items.

## ⚠️ Watch Out / Pitfalls

| Mistake                              | Why It Breaks                              | Fix                                                      |
| ------------------------------------ | ------------------------------------------ | -------------------------------------------------------- |
| `KeyError: 'key'`                    | Accessing a key that doesn't exist         | Use `.get(key)` or check `if key in dict:`               |
| `TypeError: unhashable type: 'list'` | Trying to use a list as a dictionary key   | Keys must be immutable (strings, ints, tuples)           |
| Iterating values instead of keys     | `for i in dict:` gives keys, not values    | Use `dict.values()` if you only need values              |
| Overwriting vs Appending             | `dict[key] = val` overwrites if key exists | Check `if key not in dict:` first, or use `setdefault()` |
