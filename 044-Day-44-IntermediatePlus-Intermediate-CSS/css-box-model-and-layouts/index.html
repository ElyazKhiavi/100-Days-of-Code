Box Model

Every element is a rectangle made of four layers, inside to out.

The Four Layers

/* layer order, inside → outside */
content  → text / image / children
padding  → space inside the border
border   → the edge itself
margin   → space outside the border

box-sizing

The single most important line in any stylesheet.

content-box vs border-box

/* width only counts content — padding & border are added on top */
box-sizing: content-box; /* default */

/* width includes content + padding + border */
box-sizing: border-box;

/* the universal reset — do this always */
*, *::before, *::after {
  box-sizing: border-box;
}

Margin & Padding

Margin is outside the border. Padding is inside.

Shorthand Directions

margin: 10px;                /* all sides */
margin: 10px 20px;           /* vertical | horizontal */
margin: 10px 20px 30px;      /* top | horiz | bottom */
margin: 10px 20px 30px 40px; /* top right bottom left */

margin-inline: auto;         /* center a block horizontally */
margin-block: 1rem;          /* top + bottom */

/* same for padding, except negatives are illegal */
padding: 1rem 2rem;

Overflow

What happens when content is bigger than its box.

Four Values

overflow: visible; /* default — spills out */
overflow: hidden;  /* clips, no scroll */
overflow: scroll;  /* always shows scrollbars */
overflow: auto;    /* scrollbars only if needed */
overflow: clip;    /* like hidden, not scrollable */

/* per axis */
overflow-x: hidden;
overflow-y: auto;

Div & Span

No semantic meaning. Used only when nothing else fits.

Block vs Inline

/* <div> — block-level, full width, new line */
div { display: block; }

/* <span> — inline, flows with text */
span { display: inline; }

/* inline-block — inline flow but accepts width/height */
.chip { display: inline-block; width: 100px; }

Flexbox

One dimension — lay items out in a row or column.

Container Properties

  align-items: center;          /* cross axis */

Grid vs Flexbox

The rule: Flexbox = content decides layout. Grid = layout decides where content goes.

Use casePick
Navbar / toolbarFlexbox
Center one thingFlexbox
Card grid / galleryGrid
Full page layoutGrid
Dashboard structureGrid
List of items, unknown countFlexbox
Sticky footerFlexbox
Overlapping layoutGrid
Anything 2-dimensionalGrid

Position

Remove an element from normal flow, or stick it to an edge.

Five Values

position: static;   /* default */
position: relative; /* offsets from its own spot, still takes space */
position: absolute; /* out of flow, positioned to nearest positioned ancestor */
position: fixed;    /* out of flow, positioned to viewport */
position: sticky;   /* relative until scroll threshold, then sticks */

/* inset shorthand for top / right / bottom / left */
inset: 0;

/* sticky header */
.sticky-header {
  position: sticky;
  top: 0;
  z-index: 10;
}
