# Day 44 — Intermediate CSS

## Core Concepts
- **Box model** — content → padding → border → margin; `box-sizing: border-box` (universal reset) makes `width` include padding + border.
- **Margin collapse** — adjacent vertical margins collapse to the larger value; absent in flex/grid/absolute layouts.
- **Flexbox** — one dimension; `justify-content` (main axis), `align-items` (cross axis), `gap`, `flex: 1`.
- **Grid** — two dimensions; `fr` units, `repeat(auto-fill, minmax())` responsive tracks, `grid-template-areas` named layouts.
- **Decision rule** — Flexbox: content decides layout. Grid: layout decides where content goes.
- **Color models** — named, hex (incl. alpha), `rgb()`/`hsl()` (modern space syntax), `hwb`, `lab`/`lch`, `oklab`/`oklch`, `color(display-p3)`, `color-mix()`, `light-dark()`.
- **Typography** — absolute vs relative units (`rem` safest, `clamp()` fluid), weight 100–900 (variable fonts take any value), font stacks with generic fallbacks, Google Fonts via `preconnect` + `display=swap` or self-hosted `@font-face`.
- **Positioning** — static/relative/absolute/fixed/sticky; `inset` shorthand; `z-index` within stacking contexts.

## Syntax / Key Commands
```css
*, *::before, *::after { box-sizing: border-box; }
.gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); gap: 1rem; }
.center { display: flex; justify-content: center; align-items: center; min-height: 100vh; }
font: italic small-caps bold 16px/1.5 'Inter', sans-serif;
```

## Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| Surprise box widths | Default `content-box` adds padding/border on top of `width` | Universal `box-sizing: border-box` reset |
| Expecting sum of vertical margins | Collapse takes the larger | Use `gap` in flex/grid layouts; collapse only affects adjacent block siblings |
| `em` compounding unexpectedly | Scales from parent's font-size | Prefer `rem` for predictable scaling |
| `outline: none` on interactive elements | Visual cleanup | Replace with a `:focus-visible` ring, never bare removal |
| Canvas export fails with security error | Drawing a cross-origin image without CORS approval | `crossOrigin = "anonymous"` + a host that sends CORS headers (Unsplash does) |
