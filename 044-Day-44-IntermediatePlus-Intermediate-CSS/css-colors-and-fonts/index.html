Font Shorthand

Order matters. font-size and font-family are required.

Full Syntax

/* style  variant  weight  stretch  size/line-height  family */
font: italic small-caps bold 16px/1.5 'Inter', sans-serif;

/* minimal */
font: 16px 'Inter', sans-serif;

/* system shortcuts */
font: menu;
font: caption;
font: icon;
font: message-box;

italic small-caps bold 16px/1.5 'Inter', sans-serif

20px 'Playfair Display', serif

font: menu — uses the OS menu font

font: caption — uses the OS caption font
