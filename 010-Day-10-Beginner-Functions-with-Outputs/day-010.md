# 📗 Day 10 — Functions with Outputs & Calculator

> [!IMPORTANT] Core Concepts
>
> - **`return` Statements** — Outputs data from a function and exits it immediately. Allows function results to be assigned to variables.
> - **First-Class Functions** — Functions can be assigned to variables and passed as arguments to other functions.
> - **Docstrings** — `""" """` used for multiline module/function documentation (not just greyed-out comments).
> - **String Methods** — `.title()`, `.capitalize()` for formatting outputs cleanly.
> - **Recursion (Intro)** — A function calling itself. Angela introduced it, but noted it's better to use `while` loops for now to avoid Call Stack overflows.

### Functions with Outputs & First-Class Functions

```python
# Basic Return
def format_name(first, last):
    return f"{first} {last}".title()

name = format_name("dante", "elyazkhiavi")  # "Dante Elyazkhiavi"

# Passing functions as values
def multiply(a, b): return a * b
my_operation = multiply
print(my_operation(8, 8))  # 64
```

### Custom Float Validation (Crucial Edge Case)

`.isdigit()`, `.isdecimal()`, and `.isnumeric()` all fail on floats (`"3.14"`) and negative numbers. 

```python
def is_float(s):
    s_no_minus = s.lstrip('-')
    if not s_no_minus or s.count("-") > 1: return None
    if s_no_minus.count('.') > 1: return None
    s_no_dot = s_no_minus.replace('.', '', 1)
    if not s_no_dot or not s_no_dot.isdigit(): return None
    return float(s)

# MUST use `is not None` because 0.0 is falsy!
if is_float(user_input) is not None:
    # proceed
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `.isdigit()` on floats | Fails on `"3.14"` (returns False) | Write a custom string parsing function or use `try/except float():` (learned later) |
| Falsy Zero in Validation | `if is_float("0.0"):` fails because `0.0` is falsy in Python | Have validation return `None` on fail, and check `if is_float(val) is not None:` |
| Deep Recursion | Function calling itself infinitely | Use a `while True:` loop with a `break` condition instead of recursion |
| Missing `return` | Function outputs `None` implicitly | Ensure all logic branches return the expected data type |
