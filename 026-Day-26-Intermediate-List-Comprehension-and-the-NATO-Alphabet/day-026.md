# 📗 Day 26 — List Comprehension and the NATO Alphabet

> [!IMPORTANT]
>
> - **List Comprehension** — A concise, one-line way to create lists. Syntax: `[new_item for item in list]`.
> - **Conditional List Comprehension** — Filtering items during creation. Syntax: `[new_item for item in list if test]`.
> - **Dictionary Comprehension** — Creating dictionaries dynamically. Syntax: `{new_key: new_value for item in list}`.
> - **Pandas `.iterrows()`** — Looping through a DataFrame row by row, allowing dictionary comprehension directly from CSV data.

---

## Syntax / Key Commands

### List Comprehension
```python
# Basic
nums = [1, 2, 3]
plus_one = [n + 1 for n in nums]  # [2, 3, 4]

# Conditional (Filtering)
names = ["Alex", "Caroline"]
short_names = [name for name in names if len(name) <= 4]  # ["Alex"]

# Iterating a string (numbers are not iterable directly)
my_num = 123
num_list = [int(n) for n in str(my_num)]  # [1, 2, 3]
```

### Dictionary Comprehension
```python
# From a list
students = ["Alice", "Bob"]
grades = {name: random.randint(1, 100) for name in students}

# From an existing dictionary
passed = {name: grade for (name, grade) in grades.items() if grade >= 60}
```

### Pandas `.iterrows()`
```python
import pandas as pd
df = pd.read_csv("data.csv")
# Creates a dict using DataFrame rows
new_dict = {row.key: row.value for (index, row) in df.iterrows()}
```

### NATO Alphabet Generator 🎙️ (Main Project)
> 📂 [**View source →**](nato-alphabet/main.py)

Reads the NATO phonetic alphabet from a CSV using Pandas. Converts the DataFrame into a dictionary using `.iterrows()`. Takes user input, converts it to uppercase, and generates a list of phonetic codes using list comprehension.

**Core Logic:**
```python
data = pd.read_csv("./nato_phonetic_alphabet.csv")
nato_dict = {row.letter: row.code for (i, row) in data.iterrows()}

user_input = input("Word: ").upper()
phonetic_codes = [nato_dict[letter] for letter in user_input if letter in nato_dict]
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `TypeError: 'int' object is not iterable` | Trying to loop through an integer directly | Convert to string first: `[int(n) for n in str(my_num)]` |
| Dictionary comp missing `.items()` | Trying to iterate a dict directly for key, value | Must use `for (key, value) in dict.items()` |
| Overwriting original list | Modifying a list instead of creating a new one | List comprehensions create *new* lists by default |
| Pandas row access syntax | Using `row['col']` instead of attribute access | Use `row.column_name` (e.g., `row.letter`) for cleaner comprehension syntax |
