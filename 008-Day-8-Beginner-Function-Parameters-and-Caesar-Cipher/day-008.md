# 📗 Day 8 — Function Parameters & Caesar Cipher

> [!IMPORTANT] Core Concepts
>
> - **Parameters vs Arguments** — Parameters are placeholders in `def`; arguments are actual values passed when calling.
> - **Positional Arguments** — Matched by position (order matters): `func(a, b)` called as `func(x, y)`.
> - **Keyword Arguments** — Matched by name: `func(b=10, a="hello")` → order irrelevant.
> - **Default Values** — `def func(x=10):` — fallback if caller omits the argument.
> - **`return` statement** — Outputs data from a function (preview of Day 10).
> - **Caesar Cipher** — Classic encryption using character shifting and modulo (`%`) math.

---

## Syntax / Key Commands

### Function Definitions & Calls

```python
# Basic definition and call
def greet_with(name, location):
    print(f"Hello {name}, from {location}.")

# Positional (order matters)
greet_with("Dante", "NYC")  

# Keyword (order irrelevant)
greet_with(location="NYC", name="Dante")  

# Default values
def greet(name="Guest"):
    print(f"Hi {name}")
```

### Return Values

```python
def add(a, b):
    return a + b

result = add(5, 3)  # result = 8
```

```python
def caesar_cipher(text, shift, direction="encode"):
    if direction == "decode":
        shift *= -1  # reverse shift for decoding
    
    for i in text:
        if i.lower() in alphabet:
            # Modulo 26 wraps around the alphabet
            txt += alphabet[(alphabet.index(i.lower()) + shift) % 26]
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Breaks | Fix |
| --- | --- | --- |
| `UnboundLocalError` | Used variable before defining it inside a function | Initialize ALL accumulators (`score=0`) **before** loops |
| `IndexError` | Empty string `""[0]` crashes | Validate input (`if string:`) before indexing |
| Mixing positional args | `func(a,b)` called as `func(b,a)` → values swap silently | Use keyword args when order is ambiguous |
| Forgetting `return` | Function returns `None` implicitly | Explicitly `return` the desired output |
| Shift wrapping | `index + shift` exceeds list length | Use modulo: `(index + shift) % len(alphabet)` |
