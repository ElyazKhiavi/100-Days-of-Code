# 📗 Day 33 — API Endpoints & API Parameters - ISS Overhead Notifier

## Core Concepts
- **API** — messenger between applications; client requests → server responds.
- **Endpoint** — the URL that exposes a specific resource (`/users`, `/iss-now.json`).
- **Parameters** — query (`?key=value&...`), path (`/users/123`), header (auth), or body (POST) options that customize the response.
- **requests** — `requests.get(url, params=...)` → `raise_for_status()` → `.json()`.
- **HTTP status codes** — 1XX informational, 2XX success, 3XX redirect, 4XX client error, 5XX server error.

## Syntax / Key Commands
```python
response = requests.get(url=ENDPOINT, params=PARAMS)  # params dict → query string
response.raise_for_status()                           # raise on 4XX/5XX
data = response.json()                                # JSON → dict/list
```

## HTTP Status Codes Reference

| Code | Meaning | When |
|------|---------|------|
| 200 / 201 / 204 | OK / Created / No Content | Success (GET+PUT+PATCH / POST / DELETE) |
| 301 / 302 / 304 | Moved / Found / Not Modified | Redirects & caching |
| 400 / 401 / 403 | Bad Request / Unauthorized / Forbidden | Client mistakes |
| 404 / 429 | Not Found / Too Many Requests | Missing resource / rate limit |
| 500 / 502 / 503 / 504 | Server crashes & gateway failures | Server-side problems |

**4XX** → check your request (URL, params, headers, auth). **5XX** → retry with backoff; it's not you.
Full list: [MDN — HTTP Status](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status)

## Watch Out / Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| `MY_LONG - 5 <= iss_latitude <= MY_LONG + 5` | Copy-paste of the latitude block; **no exception raised**, silently wrong | Use `iss_longitude` in the second condition |
| `smtplib.SMTP("SMTP_LINK")` | Quotes turn the variable into a string literal | `smtplib.SMTP(SMTP_LINK)` |
| Comparing API (UTC) hours to `datetime.now()` | `formatted=0` returns UTC; local clock is not UTC | `datetime.now(timezone.utc).hour` |
| Unhandled `ConnectionError` on flaky APIs | open-notify is HTTP-only and goes down | Wrap `requests.get` in `try/except requests.exceptions.ConnectionError` |
| Mixing up 401 / 403 | Both mean "no" | 401 = not authenticated; 403 = authenticated, not allowed |
