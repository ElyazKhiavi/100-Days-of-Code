# 📗 Day 29 — Building a Password Manager GUI App with Tkinter

## Core Concepts

- **`random` vs `secrets`** — `random` is a PRNG (predictable, good for games). `secrets` is a CSPRNG (cryptographically secure, draws OS entropy). `secrets` must be used for passwords.
- **Raw Strings (`r""`)** — Treats backslashes as literal characters. Prevents escape sequence errors in Regex and long alphabets.
- **`any()` function** — Returns `True` if any element in an iterable is true. Used to check for uppercase/digits in strings.
- **`pyperclip`** — External module to copy text directly to the system clipboard.
- **Regex Validation** — Using `re.match()` to validate website URL formats.

## Syntax / Key Commands

### Secure Password Generation

```python
import secrets
alphabet = r"""abc...XYZ123!@#"""
password = "".join(secrets.choice(alphabet) for i in range(26))
```

### Input Validation with `any()`

```python
if not any(c.isdigit() for c in password):
    print("Must contain a digit")
```

### Clipboard Copy

```python
import pyperclip
pyperclip.copy(password)
```

## Watch Out / Pitfalls

| Mistake                           | Why It Happens                            | Fix                                          |
| --------------------------------- | ----------------------------------------- | -------------------------------------------- |
| Using `random` for passwords      | `random` is deterministic and predictable | Use `secrets.choice()`                       |
| `ModuleNotFoundError`             | Module not installed or mistyped          | Run `pip install <module>` or check spelling |
| Escape sequence errors in strings | Backslashes `\` trigger escapes           | Use raw strings `r"..."`                     |
