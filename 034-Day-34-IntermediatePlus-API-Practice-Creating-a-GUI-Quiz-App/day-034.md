# 📗 Day 34 — API Practice & Type Hints - Quizzler GUI App

## Core Concepts

- **Type hints** — optional labels (`name: str`, `-> int`) for readability, IDE support, and static checkers (`mypy`). Not enforced at runtime; never a substitute for validation or casting.
- **`html.unescape()`** — OpenTDB returns HTML entities (`&quot;`, `&#039;`); unescape before displaying.
- **API-driven data** — questions fetched live from OpenTDB with a `params` dict, replacing Day 17's hardcoded list.
- **Layered OOP architecture** — `data` (fetch) / `question_model` (model) / `quiz_brain` (logic) / `ui` (view).
- **UI feedback loop** — flash green/red → `after(700, ...)` → next question → `state='disabled'` at the end.

## Project: Quizzler App — [quizzler-app/](./quizzler-app/)

Day 17's terminal quiz rebuilt as a tkinter GUI with live questions from [OpenTDB](https://opentdb.com/) (10 boolean questions, category 15). Click true/false → background flashes green/red → next question after 700 ms → final score screen with disabled buttons.

- `data.py` — fetch + parse; exposes `question_data` at module level
- `question_model.py` — `Question(text, answer)`
- `quiz_brain.py` — `still_has_questions()`, `show_question()` (with `html.unescape`), `check_answer()`
- `ui.py` — score label, question label, true/false image buttons, end-game state

## Watch Out / Pitfalls

| Mistake                                           | Why It Happens                                                                                                                                                                                                           | Fix                                                                                             |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `still_has_questions()` returns `current == len`  | Inverted semantics — True only when the quiz is **over**. UI's check was inverted too, so the app worked via double negation until the class gets reused                                                                 | `current < len` in the brain **and** `if not still_has_questions():` in the UI — apply together |
| `check_answer(self, user_answer: int)`            | Method receives `"true"`/`"false"` strings and calls `.lower()`; hints aren't enforced so Python stayed silent                                                                                                           | `user_answer: str`                                                                              |
| `ImportError: cannot import name 'question_data'` | Imported a name before the source module defined it (incomplete save / write order)                                                                                                                                      | Import**Error** = module found, name missing; Module**NotFoundError** = module itself missing   |
| Garbled quotes in questions                       | OpenTDB encodes `"` as `&quot;`, `'` as `&#039;`                                                                                                                                                                         | `html.unescape()` before display                                                                |
| Network call at import time                       | `question_data = get_questions()` runs on import — dead API kills the app at startup (`ConnectionError`, see [Day 33](../033-Day-33-IntermediatePlus-API-Endpoints-and-API-Parameters-ISS-Overhead-Notifier/day-033.md)) | try/except around the fetch, or fetch lazily                                                    |
| Unused code                                       | `Canvas` import, `API_URL`, `BTN_SIZE` left over from refactoring                                                                                                                                                        | Delete                                                                                          |
