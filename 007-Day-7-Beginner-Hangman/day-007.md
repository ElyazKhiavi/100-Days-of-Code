## Syntax / Key Patterns

### 1. Custom Module Imports

Splitting code into separate files improves readability and maintainability.

```python
from hangman_words import easy_words, hard_words
from hangman_logo import logo, HANGMANPICS

word = random.choice(easy_words)
```

### 2. The Game Loop & State Management

Using a boolean flag to keep the game running until a win/loss condition is met.

```python
lives = 6
game_over = False
correct_letters = []

while not game_over:
    guess = input("Guess a letter: ").lower()
    # ... update state based on guess ...
```

### 3. Display Rebuilding (String Concatenation)

Rebuilding the display string from scratch every iteration based on current state.

```python
display = ""
for letter in word:
    if letter in correct_letters:
        display += letter
    else:
        display += "_"
```

### 4. Conditional Branching & Deduction

```python
if guess in correct_letters:
    print("Already guessed!")
elif guess in word:
    correct_letters.append(guess)  # State update
else:
    lives -= 1                     # Penalty
    print(HANGMANPICS[lives])      # UI update
```

## ⚠️ Watch Out / Pitfalls

| Mistake                                           | Why It Happens                                           | Fix                                                                                    |
| ------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Forgetting to add guessed letter to tracking list | Letter shows up correctly once but not on repeat guesses | Always `append()` to `correct_letters` immediately when user guesses right             |
| Off-by-one in HANGMANPICS index                   | Shows wrong stage (e.g., empty noose instead of head)    | Index `lives` directly — when `lives=6` show index 6 (full body), decrement from there |
| Not breaking out of loop after win/loss           | Game continues after it should end                       | Set `game_over = True` and check condition at the START of the next iteration          |
| Case sensitivity in guesses                       | User types "A" but word has "a" → marked wrong           | `.lower()` all inputs immediately                                                      |
