```python

from hangman_logo import logo, HANGMANPICS

# 2. Random choice (Day 4)

# 3. While loop + game state (Day 6)

    # ... game logic ...

# 4. Conditional branching (Day 3)
if guess in word:
    # correct path
elif guess in letter_list:
    # already guessed
else:
    lives -= 1  # wrong path

# 5. For loop for display rebuild (Day 5)
for letter in word:
    if letter in letter_list:
        display += letter
    else:
        display += "_"

# 6. Function encapsulation (Day 6)
def play_game():
    # ... game logic ...
def main():
    play_game()
    # Replay loop
    while True:
        again = input("Play again? (y/n): ").lower()
        if again == "y":
            play_game()
        else:
            break
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| Forgetting to add guessed letter to tracking list | Letter shows up correctly once but not on repeat guesses | Always `append()` to your `correct_letters` list when user guesses right |
| Off-by-one in HANGMANPICS index | Shows wrong stage (e.g., empty noose instead of head) | Index `lives` directly — when lives=6 show index 6 (full body), decrement from there |
| Not breaking out of inner loop after win/loss check | Game continues after it should end | Set `game_over = True` before checking win/lose; check at START of next iteration |
| Case sensitivity in guesses | User types "A" but word has "a" → marked wrong | `.lower()` all inputs immediately |
