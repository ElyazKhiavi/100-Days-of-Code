# Day 36 — Stock Trading News Alert

## Core Concepts
- **API chaining** — stock delta check gates the news fetch, which feeds the notification. No trigger = no downstream calls.
- **Alpha Vantage `TIME_SERIES_DAILY`** — free tier: 25 requests/day, includes daily/weekly/monthly series; intraday and advanced functions are premium. Series is returned reverse-chronological.
- **Trading-day gaps** — the last two series entries are the last two trading days; weekends and holidays require no calendar math.
- **Rate-limit payloads** — when capped or erroring, Alpha Vantage replaces the data key with `"Note"` or `"Error Message"`; guard by key presence.
- **NewsAPI `/v2/everything`** — `q`, `searchIn`, `from`/`to` (`YYYY-MM-DD`), `sortBy`; free tier 100 req/day, 1-month lookback.
- **`email.message.EmailMessage`** — structured message construction; `SMTP.sendmail` returns a dict of refused recipients.

## Project: Stock News Alert — [stock-news/main.py](./stock-news/main.py)
Compares the closing prices of the two most recent trading days; a move beyond ±2% (course spec: ±5%) fetches up to 3 articles (`searchIn="title"`, bounded by the two dates) and sends an alert email. Course delivers via Twilio SMS; Twilio is inaccessible in this region — transport is SMTP. Secrets load from `.env` via `python-dotenv`.

## Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| `KeyError` on `"Time Series (Daily)"` | Free-tier cap returns `"Note"`/`"Error Message"` instead of data | Key-presence guard before parsing |
| Assuming series ordering | JSON objects carry no order guarantee; current code relies on API insertion order | `sorted(series.items(), reverse=True)[:2]` if hardening |
| Missing silent refusals | `sendmail` returns refused recipients as a dict | Check the dict, log code + reason |
| Calendar-date math for market gaps | Assuming Mon–Fri trading | Compare the last two series entries |
| Secrets in source | Convenience | Six values in `.env`; ship `.env.example` with keys only |
