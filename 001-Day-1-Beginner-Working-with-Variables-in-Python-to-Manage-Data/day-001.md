# 📗 Day 1 — Variables & Basic I/O

> [!IMPORTANT] Core Concepts
>
> - **`print()`** → outputs to console; supports `\n` escape chars & `*` repetition
> - **`input()`** → prompts user, returns **string** (always!)
> - **Variables** → label for stored data; assignment via `=`
> - **String Concatenation** → `+` joins strings; `f""` (f-strings) for interpolation
> - **`len()`** → returns length of a string (or sequence)
> - **Variable Naming** → `snake_case` preferred; no spaces, no starting with numbers

---

## Syntax / Key Commands

```python
# Print basics
print("Hello\nWorld")          # newline escape
print("Ha" * 3)                # HaHaHa (string repetition)

# Input always returns a STRING
name = input("Your name? ")    # type(name) == str

# String concatenation vs f-string
print("Hi " + name)            # manual concatenation
print(f"Hi {name}")            # f-string (cleaner)

# Length
print(len(name))               # character count
```

### Variable Naming Rules

| ✅ Valid   | ❌ Invalid  |
| ---------- | ----------- |
| `my_name`  | `my-name`   |
| `_private` | `2nd_place` |
| `userName` | `user name` |

**Convention:** `snake_case` for variables in Python.

## ⚠️ Watch Out / Pitfalls

- **`input()` always returns a string** — even if user types a number. Use `int()` / `float()` to convert if needed (covered later).
- **Can't concatenate string + int** → `print("Age: " + 25)` ❌ → use f-string instead.
- **`len()` counts every character**, including spaces and punctuation.
