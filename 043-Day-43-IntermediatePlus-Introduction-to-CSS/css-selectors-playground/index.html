Basic Selectors

Tag p

Selects every element of that name (scoped here to the demo).

p { color: #2b2b2b; line-height: 1.6; }

This paragraph is styled by the tag selector.

So is this one.

Class .tag

Selects every element with that class — reusable.

.tag { background: #bae1ff; border-radius: 999px; }
Design CSS Frontend

ID #hero

Selects one unique element on the page.

#hero { background: linear-gradient(...); }

The hero at the top of this page uses #hero.

Universal *

Selects every element. Usually for resets.

* { box-sizing: border-box; }

This page uses * to reset margin and padding.

Modern Selectors

:is(a, b, c)

Matches any of the listed selectors.

.is-demo :is(h4, p) { color: #09005b; }

Heading

Paragraph

Span (not matched)

:where(a, b)

Like :is() but zero specificity.

.where-demo :where(h4, p) { border-left: 4px solid #ffdfba; }

Heading

Paragraph

:has(selector)

Parent selector — styles an element that contains a match.

.has-demo:has(.star) {
  background: #ffffba;
}
Plain box (no star inside)
Box with ★ inside — highlighted.

:focus-visible

Only when focused via keyboard (Tab key).

.kv-btn:focus-visible {
  outline: 3px solid #2f004d;
}

:focus-within

Parent gets styled when any child is focused.

.fw:focus-within {
  background: #ffdfba;
}
