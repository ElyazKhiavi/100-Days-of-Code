### learning tuples

the tuples data type in python

tuples are just like lists, well almost,
tuples are carved in stone one created they can not be modified !
they are immutable 🪨

because tuples are immutable and generate constant values that do not change we may use them for things like colors in our site that are unlikely to change after being generated 

you can however turn a tuple into a list and modify it if you need to 
```python
my_tuple = ('color_1', 'color_2')
my_list = list(my_tuple)
```
