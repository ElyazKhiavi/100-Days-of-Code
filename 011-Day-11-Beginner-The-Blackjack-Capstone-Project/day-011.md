## Syntax / Key Patterns

### The Ace Logic (11 vs 1)
If a hand contains an Ace (11) and busts (> 21), the Ace value drops to 1.
```python
def calculate_score(hand):
    if sum(hand) == 21 and len(hand) == 2:
        return 0  # Blackjack
    if 11 in hand and sum(hand) > 21:
        hand[hand.index(11)] = 1  # Ace drops to 1
    return sum(hand)
```

### Dealer AI Loop
Dealer must keep drawing cards until score is 17 or higher.
```python
def dealer_play():
    while computer_sum() < 17:
        computer_cards.append(pick_a_card())
```

### Hidden vs. Revealed State
Controlling what the user sees based on game phase.
```python
def show_hands(hide_dealer=True):
    print(f"\nYour hand: {player_cards}  →  Score: {player_sum()}")
    if hide_dealer:
        print(f"Dealer hand: [{computer_cards[0]}, ?]")  # Hide 2nd card
    else:
        print(f"Dealer hand: {computer_cards}  →  Score: {computer_sum()}")
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| Forgetting Ace logic | Ace = 11 causes immediate busts (e.g., Ace + 10 + 5 = 26) | Check `if 11 in hand and sum > 21` and replace `11` with `1` |
| Dealer drawing forever | No exit condition for dealer loop | `while dealer_score < 17:` ensures dealer stops at 17+ |
| Comparing scores early | Player hasn't stood yet, but code checks winner | Only run `check_winner()` after player breaks the Hit loop |
| Not resetting hands | Cards from previous game carry over | Call `deal_starting_hands()` which clears the lists at the start of `play_round()` |
