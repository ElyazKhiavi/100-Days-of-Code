# 📗 Day 3 — Control Flow & Logical Operators

> [!IMPORTANT] Core Concepts
>
> - **`if` / `elif` / `else`** — branching logic; code runs conditionally based on True/False
> - **Comparison Operators:** `==`, `!=`, `<`, `>`, `<=`, `>=` — compare values, return bools
> - **Logical Operators:** `and` (both true), `or` (either true), `not` (flips truth value)
> - **Modulo `%`** — returns remainder of division; perfect for odd/even checks
> - **Nested Conditionals** — `if` inside `if`; chain as deep as logic requires
> - **`.lower()`** — normalizes user input for case-insensitive comparisons

---

## Syntax / Key Commands

### Basic If/Elif/Else

```python
if condition:
    # runs when condition is True
elif another_condition:
    # runs when if was False but this is True
else:
    # runs when nothing above matched
```

### Comparison Operators

| Operator | Meaning          | Example         |
| -------- | ---------------- | --------------- |
| `==`     | Equal to         | `age == 18`     |
| `!=`     | Not equal to     | `name != ""`    |
| `>`      | Greater than     | `score > 80`    |
| `<`      | Less than        | `temp < 0`      |
| `>=`     | Greater or equal | `height >= 120` |
| `<=`     | Less or equal    | `age <= 12`     |

```python
score = int(input("Score? "))
if score >= 100:
    print("Bullseye 🎇")
elif score >= 80:
    print("Excellent 🪭")
elif score >= 60:
    print("You did well 👍")
else:
    print("You failed 😿")
```

### Logical Operators

```python
# AND — both must be True
if age > 12 and height > 120:
    print("Can ride")

# OR — at least one must be True
if size == "M" or size == "L":
    bill += 3

# NOT — flips the boolean
if not can_ride:
    print("Too short!")
```

| A   | B   | `A and B` | `A or B` | `not A` |
| --- | --- | --------- | -------- | ------- |
| T   | T   | T         | T        | F       |
| T   | F   | F         | T        | F       |
| F   | T   | F         | T        | T       |
| F   | F   | F         | F        | T       |

### Modulo Operator (`%`)

Returns the **remainder** after division — essential for parity checks.

```python
7 % 2   # 1  (odd)
8 % 2   # 0  (even)
13 % 5  # 3
30 % 20 # 10
100 % 51# 49
```

**Odd / Even pattern:**

```python
num = int(input("Enter a number: "))
if num % 2 == 0:
    print("Even")
else:
    print("Odd")
```

### Nested Conditionals

```python
if outer_condition:
    if inner_condition:
        # both matched
    elif another_inner:
        # outer yes, inner elif
    else:
        # outer yes, nothing else
elif other_outer:
    pass
else:
    pass
```

### Input Normalization with `.lower()`

```python
choice = input("Yes or no? ")  # User might type "YES", "yes", "Yes"...
if choice.lower() == "yes":    # .lower() normalizes everything
    print("Confirmed!")
```

### Multi-line Strings & Escape Characters

```python
# Triple quotes for multi-line print
print('''Line 1
Line 2
Line 3''')

# Backslash escape for illegal characters
print("She said \"Hello\"")  # escapes the inner quotes
```

## ⚠️ Watch Out / Pitfalls

| Mistake                                        | Why It Breaks                             | Fix                                        |
| ---------------------------------------------- | ----------------------------------------- | ------------------------------------------ |
| `if x = 5:`                                    | Single `=` is assignment, not comparison! | Use `==` for comparison                    |
| `===` in Python                                | That's JavaScript — doesn't exist here    | Use `==` only                              |
| Forgetting colons `:` after `if`/`elif`/`else` | SyntaxError                               | Always end condition line with `:`         |
| Wrong indentation                              | Python uses whitespace, not `{}`          | Indent consistently (4 spaces)             |
| `if "Yes"` matches only exact case             | User might type "YES" or "yes"            | Use `.lower()` first                       |
| Chaining `if` instead of `elif`                | Every `if` is checked independently       | Use `elif` for mutually exclusive branches |
