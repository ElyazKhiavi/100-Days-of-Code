# 📗 Day 2 — Data Types, String Manipulation & Math

> [!IMPORTANT]
>
> - **Data Types:** `str`, `int`, `float`, `bool` — know which one you're holding
> - **`type()`** → inspect a variable's data type; **`len()`** only works on sequences (not numbers)
> - **Type Conversion:** `int()`, `str()`, `float()`, `bool()` — convert between compatible types
> - **String Subscripting:** index from `0`; negative indices count from the end (`[-1]` = last char)
> - **Math Operators:** `+`, `-`, `*`, `/` (always float), `//` (floor), `%` (remainder), `**` (power)
> - **F-Strings:** `f"text {variable}"` — clean interpolation of any type inside strings
> - **PEMDAS:** Python follows standard operator precedence; use `()` to force order

---

## Syntax / Key Commands

### Data Types

```python
# String
name = "Alice"              # str — text in quotes

# Integer
age = 25                    # int — whole numbers
big_num = 1_000_000         # underscores for readability (ignored by Python)

# Float
pi = 3.14159                # float — decimal numbers

# Boolean
is_student = True           # bool — only True or False (capitalized!)
```

### String Subscripting (Indexing)

```python
text = "Python"
text[0]     # 'P'        (first character)
text[-1]    # 'n'        (last character)
text[0:3]   # 'Pyt'      (slicing — covered later)
```

### Type Checking & Conversion

```python
# Check type
type(42)          # <class 'int'>
type("hello")     # <class 'str'>

# Convert
int("42")         # 42         (string → int)
str(42)           # "42"       (int → string)
float(42)         # 42.0       (int → float)
bool(0)           # False      (only 0, 0.0, "", False → False; else → True)

# Common pattern: input() returns str → convert for math
age = int(input("Your age? "))   # str → int
```

### Mathematical Operations

```python
# Basic arithmetic
10 + 3    # 13
10 - 3    # 7
10 * 3    # 30
10 / 3    # 3.333...   (always returns float!)

# Floor division (drops decimal, rounds down)
10 // 3   # 3

# Modulo (remainder of division)
10 % 3    # 1

# Exponent (power)
2 ** 5    # 32

# Assignment shortcuts
x = 10
x += 5    # x = 15   (same as x = x + 5)
x -= 3    # x = 12
x *= 2    # x =24
x /= 4    # x = 6.0   (note: becomes float!)
```

### Operator Precedence (PEMDAS)

| Priority | Operator            | Description                              |
| -------- | ------------------- | ---------------------------------------- |
| Highest  | `()`                | Parentheses                              |
|          | `**`                | Exponentiation (right-to-left)           |
|          | `+x`, `-x`          | Unary plus/minus                         |
|          | `*`, `/`, `//`, `%` | Mult, div, floor, modulo (left-to-right) |
| Lowest   | `+`, `-`            | Add, subtract (left-to-right)            |

### Number Manipulation

```python
round(10 / 3)       # 3      (rounds to nearest integer)
round(10 / 3, 1)    # 3.3    (rounds to 1 decimal place)
round(10 / 3, 2)    # 3.33   (rounds to 2 decimal places)
```

### F-Strings

```python
name = "Senna"
age = 17
score = 95.5

# Clean interpolation — no more messy + concatenation!
print(f"Name: {name}, Age: {age}, Score: {score}")
# Output: Name: Senna, Age: 17, Score: 95.5

# Operations work inside {}
print(f"Next year: {age + 1}")
# Output: Next year: 18
```

## ⚠️ Watch Out / Pitfalls

| Mistake                  | Why It Breaks                    | Fix                                         |
| ------------------------ | -------------------------------- | ------------------------------------------- |
| `"Age: " + 25`           | Can't concat str + int           | Use f-string: `f"Age: {25}"`                |
| `len(123)`               | Numbers have no length           | Convert first: `len(str(123))`              |
| `int("hello")`           | Not a valid integer string       | Validate input or catch ValueError          |
| `9 / 3` expecting `3`    | `/` always returns float → `3.0` | Use `//` if you need int, or `int(9/3)`     |
| `true` instead of `True` | Python is case-sensitive         | Booleans are `True` / `False` (capitalized) |
