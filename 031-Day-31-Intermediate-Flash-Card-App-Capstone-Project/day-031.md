# 📗 Day 31 — Flash Card App Capstone Project

## Core Concepts

- **Pandas Data Manipulation** — Converting CSV data into a list of dictionaries using `data.to_dict(orient="records")` for easy random selection.
- **Tkinter Canvas Image Swapping** — Changing the background image of a canvas item using `canvas.itemconfig(item_id, image=new_image)`.
- **Event-Driven State Changes** — Using `root.after()` to trigger a card flip after 3 seconds, and `root.after_cancel()` to stop it if the user clicks early.
- **Dynamic CSV Writing** — Removing known words from the list and writing the remaining words back to a new CSV file to track learning progress.

## Syntax / Key Commands

### Pandas to Dictionary List
```python
import pandas as pd
data = pd.read_csv("french_words.csv")
words_list = data.to_dict(orient="records") 
# Result: [{"French": "partie", "English": "part"}, ...]
```

### Saving Progress Without Index

```python
df = pd.DataFrame(words_list)
```

## Projects

### Flash Card App 🃏 (Capstone Project)
> 📂 [**View source →**](flash-card-project/main.py)

A GUI flash card application to help learn a new language (French/German).

- **UI:** A canvas displaying a card background image, with Title and Word text overlaid. Right (✓) and Wrong (✗) buttons below.
- **Logic:** 
  1. A random word is picked from the CSV.
  2. The foreign word is shown.
  3. After 3 seconds (`root.after`), the card "flips" (image changes) to show the English translation.
  4. If the user clicks "Right", the word is removed from the list, and the remaining words are saved to `to_learn.csv`.
  5. The app prioritizes loading `to_learn.csv` on startup if it exists, so the user doesn't restart from scratch.

## Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| CSV grows with duplicate index columns | `df.to_csv()` saves the DataFrame index by default | Pass `index=False` to `to_csv()` |
| Card flips even after clicking "Next" | The `after()` loop wasn't cancelled | Save the timer ID and call `root.after_cancel(timer_id)` |
| `KeyError` when accessing word | Trying to access dictionary keys that don't exist | Ensure CSV headers match the keys used in `current_word["French"]` |
