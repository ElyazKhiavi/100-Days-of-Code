# Day 41 — Introduction to HTML

## Core Concepts
- **Request flow** — Client → ISP → DNS (name → IP resolution) → Server responds; dynamic IPs route users to the nearest regional server.
- **Separation of concerns** — HTML (structure), CSS (presentation), JS (behavior).
- **Semantic HTML5** — `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>` convey meaning, not just layout.
- **CSS custom properties** — `:root` variables for palette tokens; consistent theming across pages.
- **Tailwind CSS v4 Play CDN** — zero-build utility classes via `<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4">`.

## Syntax / Key Commands
```html
<link rel="stylesheet" href="style.css" />
<script src="script.js"></script>
```
```css
:root { --blue-1: #011f4b; --blue-5: #b3cde0; }
```
```javascript
target.scrollIntoView({ behavior: "smooth" });
```

## Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| `<b>` vs `<strong>` interchangeably | Visually identical | `<strong>` = importance (semantics); `<b>` = style only |
| Stat counters re-animating every scroll | No latching | `counted` flag flips once when section enters viewport |
| Mobile nav staying open after navigation | Toggle-only menu | Close on any link click, not just button toggle |
| Cell clicks after game over | Listener still bound | Guard on `gameOver` + disable cells at `endGame` |
