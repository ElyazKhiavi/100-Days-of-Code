FAQ

Common questions, answered.

Do I need a build step?

No. This setup uses the Tailwind v4 Play CDN, so you can open the HTML file directly in a browser.

Can I customize the blue palette?

Yes. Change the arbitrary values like #005b96 to any hex you like, or define a theme in CSS.

Is JavaScript required?

Only for the mobile menu, smooth scroll, form handling, and stat counters. The layout works without it.
