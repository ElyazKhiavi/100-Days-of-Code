# 📗 Day 4 — Randomisation & Python Lists

> [!IMPORTANT] Core Concepts
>
> - **`import` / Modules** — split code into reusable files; `import` brings them in
> - **`random` module** — `randint()`, `choice()`, `random()`, `uniform()` for unpredictability
> - **Python Lists** — ordered, mutable collections; store multiple items in one variable
> - **List Methods:** `append()`, `extend()`, `insert()`, `pop()`, `remove()`, `index()`
> - **List Slicing** — `list[1:3]` extracts a sublist; negative indices count from end
> - **Nested Lists** — lists inside lists; 2D/3D data structures
> - **List Copying** — `list[:]` creates a real copy (not just a reference alias!)

## Syntax / Key Commands

### Importing Modules

```python
import random                    # import entire module
from random import choice        # import specific function
import my_module                 # import your OWN custom module

# Usage
print(random.randint(0, 10))     # random integer 0-10 (inclusive)
print(random.choice(["a", "b"])) # pick random item from list
print(my_module.message)         # access custom module contents
```

**What is a Module?** When code gets long/messy, split it into separate files. Each file is a _module_. The main entry point loads them via `import`. You can create your own modules (e.g., `my_module.py`) and import them anywhere.

### Random Module Functions

| Function               | Returns                      | Example                              |
| ---------------------- | ---------------------------- | ------------------------------------ |
| `random.random()`      | Float between 0.0 and 1.0    | `0.4729...`                          |
| `random.randint(a, b)` | Random int **inclusive** a–b | `random.randint(0, 1)` → 0 or 1      |
| `random.uniform(a, b)` | Random float between a and b | `random.uniform(1, 99)` → `45.23...` |
| `random.choice(seq)`   | Random element from sequence | `random.choice([1,2,3])` → 2         |

```python
# Heads or Tails
flip = random.randint(0, 1)
if flip == 1:
    print("Heads")
else:
    print("Tails")

# Simulating RPS choices
for i in range(10):
    r = random.randint(1, 3)
    if r == 1: print("Rock")
    elif r == 2: print("Scissors")
    else: print("Paper")
```

### Python Lists — Creating & Accessing

```python
# Basic list
fruits = ["apple", "banana", "cherry"]
print(fruits[0])       # "apple" (first)
print(fruits[-1])      # "cherry" (last)
print(fruits[1:3])    # ["banana", "cherry"] (slice)
print(type(fruits))    # <class 'list'>

# Mixed types allowed
person = ["Sam", 30, True, 1.8]

# Use in
for item in person:
    print(item, type(item))


# From user input
items = [input("Item 1: "), input("Item 2: ")]

# Duplicates allowed
nums = [1, 1, 1, 2, 3, 5, 5]  # perfectly valid
```

**Official definition:** A list is an **ordered, mutable sequence** that can hold heterogeneous data types. Used to group related data together, maintain order (like a queue), and store collections for iteration.

### List Methods — Modifying

```python
menu = ["burger", "pizza", "tacos"]

# ADD
menu.append("salad")              # add to end → ["burger", "pizza", "tacos", "salad"]
menu.insert(0, "soup")            # insert at index → ["soup", "burger", ...]
menu.extend(["fries", "drink"])   # merge another list → adds each item

# REMOVE
menu.pop()          # remove & return LAST item (or give index: menu.pop(2))
menu.remove("pizza") # remove by VALUE (first match only)

# MODIFY by index
menu[1] = "pasta"   # replace item at position 1
```

### Nested Lists

```python
matrix = [
    ["apple", "orange", "cherry"],
    ["phone", "laptop", "tablet"],
    [["airplane", "helicopter"], ["car", "truck"]],
]
print(matrix[0][1])           # "orange"
print(matrix[2][0][0])        # "airplane" (deep nesting)

# Random choice from nested list
print(random.choice(random.choice(matrix)))
```

### List Copying — Gotcha! ⚠️

```python
friends = ["Alice", "Bob", "Charlie"]

# WRONG — this creates a reference, NOT a copy
candidates = friends
candidates.append("Dave")
print(friends)  # ["Alice", "Bob", "Charlie", "Dave"] ← original changed too!

# CORRECT — slice copy creates a NEW independent list
candidates = friends[:]
candidates.append("Eve")
print(friends)    # ["Alice", "Bob", "Charlie"] ← original untouched
print(candidates) # ["Alice", "Bob", "Charlie", "Eve"] ← copy modified
```

> [!warning] Why This Matters
> Lists are **objects** (like JS arrays). Assigning `b = a` makes both variables point to the **same object in memory**. Use `a[:]` or `a.copy()` when you need an independent clone.

**The elegant win-check trick** (replaces nested `if/elif` hell):

```python
choices = ["r", "p", "s"]

# Ordered cyclically: r beats s, p beats r, s beats p
# An item beats the one TWO positions ahead (modulo 3)
user_wins = (choices.index(user) + 2) % 3 == choices.index(computer)
```

| User         | Computer | Math          | Result  |
| ------------ | -------- | ------------- | ------- |
| r (0)        | s (2)    | (0+2)%3 = 2 ✓ | **Win** |
| p (1)        | r (0)    | (1+2)%3 = 0 ✓ | **Win** |
| s (2)        | p (1)    | (2+2)%3 = 1 ✓ | **Win** |
| Any          | Same     | Equal         | Draw    |
| Other combos |          |               | Lose    |

**Features:**

- ASCII art for rock/paper/scissors (plus giant ASCII banner)
- Input validation (rejects anything except r/p/s)
- Randomized response messages from pools (win/lose/draw/invalid)
- Clean exit on invalid input using `exit()`

## ⚠️ Watch Out / Pitfalls

| Mistake                                                     | Why It Breaks                                                 | Fix                                                              |
| ----------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------- |
| `list[5]` on a 5-item list                                  | **IndexError** — valid indices are 0–4                        | Remember: length 5 → last index is 4                             |
| `dict["missing_key"]`                                       | **KeyError** — key doesn't exist                              | Use `.get(key, default)` or check `if key in dict` first         |
| `new_list = old_list`                                       | Modifying `new_list` also changes `old_list` (same object!)   | Use `old_list[:]` or `.copy()` for real clones                   |
| `from random import random` then calling `random.randint()` | Name collision — `random` is now the function, not the module | Use `import random` or `from random import randint` specifically |
| Forgetting `import random`                                  | **NameError** — `random` isn't defined                        | Always import modules before using them                          |
