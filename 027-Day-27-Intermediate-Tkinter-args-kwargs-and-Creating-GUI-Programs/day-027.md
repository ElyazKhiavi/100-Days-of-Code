# 📗 Day 27 — Tkinter, args, kwargs and Creating GUI Programs

## Core Concepts

- **Tkinter** — Python's standard built-in GUI library. Similar to basic HTML but with native Python logic.
- **Layout Managers** — How Tkinter positions widgets on the screen:
  - `pack`: Stacks items one after another (limited flexibility).
  - `place`: Uses exact x/y coordinates (like Turtle `goto`).
  - `grid`: Divides the window into an invisible grid of rows and columns (most common).
- **`*args`** — Allows unlimited positional arguments. Collected inside the function as a **tuple**.
- **`**kwargs`** — Allows unlimited keyword arguments. Collected inside the function as a **dictionary**.
- **Sets (Bonus)** — Unordered collections of unique elements. Useful for fast membership checking and math operations (union `|`, intersection `&`, difference `-`).

## Syntax / Key Commands

### Tkinter Grid Layout
```python
import tkinter as tk

root = tk.Tk()
root.title("My App")
root.minsize(500, 500)

label = tk.Label(text="Hello", font=("Helvetica", 32))
label.grid(row=0, column=0)

root.mainloop()
```

### Unlimited Arguments (*args)
```python
def add(*args):
    # args is a tuple
    return sum(args)

print(add(1, 2, 3, 4, 5))  # 15
```

### Many Keyword Arguments (**kwargs)
```python
def calculate(**kwargs):
    # kwargs is a dictionary
    print(kwargs)

calculate(add=3, multiply=5)
```

### Safe Attribute Lookup with **kwargs
```python
class Car:
    def __init__(self, **kw):
        # .get() returns None (or default) instead of crashing if key is missing
        self.make = kw.get('make')
        self.model = kw.get('model')

my_car = Car(make="Ford")
```

## Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| Mixing `pack()` and `grid()` | Tkinter cannot calculate layout sizes if both are used in the same container | Stick to ONE layout manager per window/frame (usually `grid`) |
| `KeyError` when using `**kwargs` | Accessing `kwargs['key']` directly when it wasn't passed | Use `kwargs.get('key')` or `kwargs.get('key', default_value)` |
| Forgetting `root.mainloop()` | The GUI window flashes and closes instantly | Must call `mainloop()` at the very end of the script to keep it running |
