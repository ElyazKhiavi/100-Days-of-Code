# 📗 Day 32 — Send Email (smtplib) & Manage Dates (datetime)

## Core Concepts

- **`smtplib`** — Python's built-in library for sending emails via SMTP protocol. Uses `starttls()` for secure encryption before logging in.
- **`datetime` module** — Accesses system time. `datetime.now()` provides current timestamp; `.weekday()` returns 0-6 (Monday is 0).
- **Environment Variables (`.env`)** — Storing sensitive data (passwords, emails) in a `.env` file and loading them via `os.getenv()` instead of hardcoding.
- **`str.translate()`** — A fast method for character replacement or removal using a translation table created by `str.maketrans()`.

## Syntax / Key Commands

### Sending Emails Securely
```python
import smtplib
import os
from dotenv import load_dotenv

load_dotenv()
SENDER = os.getenv("EMAIL_USER")
PASSWORD = os.getenv("EMAIL_PASSWORD")

with smtplib.SMTP("smtp.gmail.com") as connection:
    connection.starttls()  # Secure the connection
    connection.login(user=SENDER, password=PASSWORD)
    connection.sendmail(from_addr=SENDER, to_addrs="recipient@email.com", msg="Subject:Hello\n\nBody")
```

### Datetime Attributes
```python
import datetime as dt
now = dt.datetime.now()
print(now.year, now.month, now.day)
print(now.weekday())  # Monday = 0, Sunday = 6
```

### String Translation (Removing Punctuation/Chars)
```python
import string
s = "Hello, World!"
# maketrans(x, y, z) -> maps x to y, and deletes z
tab = str.maketrans("", "", string.punctuation)
clean_s = s.translate(tab)  # "Hello World"
```

## Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `smtplib.SMTPAuthenticationError` | Using standard Gmail password instead of App Password | Enable 2FA and generate a 16-character App Password |
| Hardcoding passwords | Security risk, difficult to modify | Use `.env` file and `os.getenv()` |
| Email sends without a subject | Missing subject header in `msg` parameter | Format message as: `Subject:Title\n\nBody` |
| `KeyError` when reading CSV | Headers in CSV don't match code | Use `csv.DictReader` and verify CSV headers |
