## Syntax / Key Commands

### Number Formatting
Developers can use `_` for readability, but users need commas.
```python
million = 1_000_000  # Developer readability

# User readability (f-strings)
print(f"{million:,}")  # 1,000,000

# User readability (format)
print(format(1000000, ","))  # 1,000,000
```

### String `.split()` Method
Splits a string into a list of substrings.
```python
'1,2,3'.split(',')         # ['1', '2', '3']
'1,2,3'.split(',', maxsplit=1) # ['1', '2,3']
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| Unreadable large numbers | Printing raw ints like `1000000` | Use f-string formatting: `f"{num:,}"` |
| Duplicate comparisons | `get_random()` picks the same person twice | Add a `while first == second:` loop to re-roll |
| Printing the whole dict key | Key includes name, profession, and country | Use `key.split(',')[0]` to extract just the name |
