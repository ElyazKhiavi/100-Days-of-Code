# 📗 Day 24 — Files, Directories and Paths

> [!IMPORTANT] Core Concepts
>
> - **File Handling** — Reading, writing, and appending to local files to save data between program runs.
> - **The `with` Statement** — Using context managers (`with open(...) as f:`) to automatically close files and free up resources.
> - **File Modes** — `r` (read - default), `w` (write - overwrites/creates), `a` (append - adds to end/creates).
> - **File Paths** — Relative paths (relative to current working directory) vs. Absolute paths (from the root `/`).
> - **String Manipulation** — Using `.replace("[name]", actual_name)` to template documents.

---

## Syntax / Key Commands

### Reading and Writing Files

```python
# Reading (default mode 'r')
with open("./my_file.txt") as file:
    contents = file.read()
    lines = file.readlines()  # Returns a list of lines

# Appending (mode 'a' - adds to end, creates if missing)
with open("my_file.txt", "a") as f:
    f.write("\nAnother one")

# Writing (mode 'w' - OVERWRITES entirely, creates if missing)
with open("my_new_file.txt", mode="w") as f:
    f.write("New file contents")
```

### Templating with `.replace()`
```python
letter = "Hello [name], from [sender]"
custom_letter = letter.replace("[name]", "Alice").replace("[sender]", "Bob")
```

## ⚠️ Watch Out / Pitfalls

| Mistake | Why It Happens | Fix |
| --- | --- | --- |
| `FileNotFoundError` | Trying to open a file that doesn't exist in read mode, or being in the wrong directory | Check your Current Working Directory (CWD) and use correct relative/absolute paths |
| `io.UnsupportedOperation: not writable` | Trying to `.write()` to a file opened in `r` (read) mode | Change the mode to `'w'` or `'a'` when opening the file |
| Forgetting to close files | Using `file = open(...)` without `file.close()` | Always use the `with open(...) as file:` context manager |
| Overwriting file data | Opening an existing file in `'w'` mode | Use `'a'` (append) if you want to keep existing data |
