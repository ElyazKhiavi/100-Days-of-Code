# 📗 Day 20 — Build the Snake Game Part 1

> [!IMPORTANT]
>
> - **Screen Refresh Control** — Using `screen.tracer(0)` and `screen.update()` to manually control animation frames and prevent flickering.
> - **Time Module** — `time.sleep(0.1)` to control the speed of the game loop.
> - **Reverse Iteration** — Moving snake segments from back to front so each piece takes the position of the one ahead of it.

## Syntax / Key Commands

### Manual Screen Refresh

```python
screen = turtle.Screen()
screen.tracer(0)  # Turns off automatic screen updates

while not game_over:
    screen.update()      # Manually refresh the screen
    time.sleep(0.1)      # Control game speed
    snake.move()
```

### Segment Movement (Back to Front)

To move the snake, the 3rd segment goes to the 2nd segment's position, the 2nd goes to the 1st, and the 1st moves forward.

```python
for seg_num in range(len(self.segments) - 1, 0, -1):
    new_pos = self.segments[seg_num - 1].pos()
    self.segments[seg_num].goto(new_pos)
self.head.fd(MOVE_DISTANCE)
```

### Preventing Reverse Movement

```python
def up(self):
    if self.head.heading() != DOWN:  # Can't go up if going down
        self.head.setheading(UP)
```

## ⚠️ Watch Out / Pitfalls

| Mistake                         | Why It Happens                                            | Fix                                                                                  |
| ------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Screen flickers on every move   | Turtle updates the screen automatically on every movement | Use `screen.tracer(0)` and call `screen.update()` once per loop                      |
| Segments separate/leave a trail | Moving the head first, then the body                      | Iterate backwards: move the last segment to the 2nd-to-last's position, etc.         |
| Snake reverses into itself      | Pressing 'Down' while moving 'Up'                         | Add a conditional check: `if head.heading() != DOWN:` before setting the new heading |
