# 📗 Day 12 — Scope & Number Guessing Game

> [!IMPORTANT]
>
> - **Variable Scope** — The namespace/visibility of a variable.
> - **Local vs Global** — Variables defined inside a function are local; outside are global.
> - **No Block Scope** — Unlike C or Java, Python does _not_ have block scope. Variables inside `if` or `for` blocks are still accessible globally.
> - **The `global` Keyword** — Allows modification of a global variable from inside a function (use sparingly).
> - **Constants** — By convention, variables meant to be permanent are written in `UPPER_CASE`.

---

## Syntax / Key Commands

### Variable Scope

```python
my_num = 20  # Global

def change_num():
    my_num = 15  # Local (shadows global)
    print(my_num)  # 15

change_num()
print(my_num)  # 20 (Global unchanged)
```

### Modifying Globals

```python
new_num = 39

def change_global():
    global new_num  # Now has access to modify the global scope
    new_num += 15

change_global()
print(new_num)  # 54
```

### Python Constants

```python
ADDRESS = "The Company Address."
NUMBER = 123_456_789
# By convention: always uppercase, usually never changed, only read from.
```

## ⚠️ Watch Out / Pitfalls

| Mistake                      | Why It Breaks                                             | Fix                                                               |
| ---------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------- |
| Shadowing variables          | Defining a local var with the same name as a global       | Rename the local var, or use `global` if modification is intended |
| Overusing `global`           | Makes code hard to trace and debug                        | Pass values as arguments and `return` them instead                |
| Treating `if` as block scope | Expecting `if True: x = 5` to hide `x`                    | Remember: only functions create scope in Python                   |
| Modifying immutable globals  | `count += 1` inside a function throws `UnboundLocalError` | Declare `global count` first                                      |
