# Day 39 — Capstone Part 1 — Flight Deal Finder

## Core Concepts

- **Cheapest-itinerary extraction** — `min(flights, key=lambda f: f["price"])`; multi-leg itineraries take departure from the first segment and arrival from the last.
- **Sheety read/update** — GET returns rows under the sheet key; PUT to `{endpoint}/{row_id}` wraps the payload under the sheet name.
- **SMTP notification pattern** — `smtplib.SMTP(host, 587, timeout=10)` + `starttls()` + `EmailMessage`; explicit timeout prevents indefinite hangs.
- **Environment variable typing** — `.env` values are always `str`; numeric values require explicit conversion before use.
- **Deal pipeline** — sheet lowest-price vs API cheapest → on improvement: update sheet, then email (email gated on successful sheet update).

## Pitfalls

| Mistake                                               | Why It Happens                                              | Fix                                                                    |
| ----------------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| Sheety writes "do nothing" though requests look valid | Only GET enabled in the Sheety dashboard                    | Enable PUT/POST (and DELETE) in the API settings before debugging code |
| `smtplib.SMTP(host, None)` connects to port 25        | Falsy port falls back to smtplib's default; Gmail blocks 25 | Explicit 587 + `timeout=10`; never pass `None`                         |
| `.env` numeric used without conversion                | dotenv returns `str` only                                   | `int(os.getenv(...))` with fallback                                    |
| Stale historic prices alert on everything             | Sheet prices outdated                                       | Reset the `lowestPrice` column once; sheet self-corrects thereafter    |
| Currency label mismatch                               | Search in GBP, output labeled €                             | Align the currency param and display symbol                            |
| Trusting HTTP status only                             | Course API returns `{"error": ...}` with 200                | Guard the JSON body for an `error` key                                 |
