# Day 45 — Web Scraping with Beautiful Soup

## Core Concepts
- **Why scrape** — sites without APIs, or APIs that don't expose what you need.
- **Beautiful Soup** — `pip install beautifulsoup4`; parses HTML/XML into a traversable object tree.
- **Tag lookup** — `find()` / `find_all(name=...)`; attribute access via `.get()`; CSS selectors via `select_one()` / `select()`.
- **Polite scraping** — check `robots.txt`, send a `User-Agent`, always set a `timeout`.
- **JS-rendered pages** — content injected by JavaScript isn't in the served HTML; extract embedded data (`__NEXT_DATA__` JSON for Next.js apps) instead of hunting rendered tags.
- **Robust extraction** — recursive walks with structural heuristics survive site rebuilds; hard-coded JSON paths don't.

## Syntax / Key Commands
```python
soup = BeautifulSoup(response.text, "html.parser")
soup.find_all(name="a")
soup.find(name="section", id="culture")
soup.select_one(selector="article p")
soup.select(selector="article p")
```
```python
rows = soup.select("tr.athing")            # CSS class selector
subtext = row.find_next_sibling("tr")      # sibling traversal (HN score rows)
```

### Hacker News Scraper — [scrape_live_data_practice/main.py](./scrape_live_data_practice/main.py)

### Empire 100 Movies — [empire_100_movies/](./empire_100_movies/)
Scrapes Empire's "100 Greatest Movies" list. The page is a Next.js app, so the scraper uses two strategies: **primary** — extract the `<script id="__NEXT_DATA__">` JSON blob and recursively walk it for movie entries (heuristic: `title` + `rank`/`meta`), parsing rank/year/image per entry; **fallback** — regex parse of rendered HTML (`N) Title (Year)` headings, following img/p tags for image, director, starring). Results sorted by rank, exported to `data.json`, which drives a local HTML/JS gallery viewer (serve with `python -m http.server`).

## Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| Hunting rendered tags on a JS-rendered page | Course-era pages were static HTML | Inspect for embedded data (`__NEXT_DATA__`, JSON blobs) or use the network tab |
| Hard-coding a JSON path from one inspection | Next.js nesting varies by build | Recursive walk with a structural heuristic |
| Crashing on malformed rows | Assuming every selected node is well-formed | Guard each lookup, skip-and-continue on `None` |
| Scraping without `robots.txt` / User-Agent / timeout | Tutorial code omits etiquette | Check `robots.txt`, send identifying headers, always `timeout=` |
| Writing empty output after a silent scrape failure | No result validation | Refuse to write empty datasets; report and exit non-zero |
