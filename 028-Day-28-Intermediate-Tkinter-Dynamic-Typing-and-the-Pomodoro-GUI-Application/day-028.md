# 📗 Day 28 — Tkinter, Dynamic Typing and the Pomodoro GUI Application

## Core Concepts

- **Dynamic Typing** — Python variables can change their data type at runtime (`a = 5` then `a = "hello"`), but operations are still strictly type-checked.
- **Tkinter Canvas Widget** — A powerful widget for drawing graphics, images, and text overlays on an X/Y coordinate system.
- **Event Loop Timers (`window.after`)** — Using `root.after(1000, function, *args)` to create a countdown timer. It schedules the function to run after a delay without freezing the GUI (unlike `time.sleep()`).
- **Global State Management** — Using the `global` keyword to track timer repetitions and the active timer ID so the `reset` button can cancel it.

## Syntax / Key Commands

### Tkinter Canvas (Images and Text)

```python
canvas = tk.Canvas(width=200, height=200, highlightthickness=0)
# Overlay image
tomato_img = tk.PhotoImage(file="tomato.png")
canvas.create_image(100, 100, image=tomato_img)
# Overlay text (save the returned item id to modify later)
timer_text = canvas.create_text(100, 150, text="00:00", fill="white", font=("Courier", 24))
canvas.grid(row=1, column=1)

# Update canvas text
canvas.itemconfig(timer_text, text="25:00")
```

### Non-Blocking Timer (The `after` method)

```python
def count_down(count):
    canvas.itemconfig(timer_text, text=f"{count}")
    if count > 0:
        global timer
        # Call count_down(count - 1) after 1000ms
        timer = root.after(1000, count_down, count - 1)

# Cancel the timer
root.after_cancel(timer)
```

## Projects

### Pomodoro App 🍅 (Main Project)

> 📂 [**View source →**](pomodora/main.py)

A desktop Pomodoro timer that cycles through 25-minute work sessions, 5-minute short breaks, and a 20-minute long break after 4 work sessions.

- **UI:** Uses a `Canvas` to display a tomato background image with a countdown text overlaid on top. Background and text colors change based on the current state (Work/Break).
- **Logic:** A `reps` variable tracks the current cycle. Math modulo (`% 8`, `% 2`) determines if it's a work or break session.
- **Reset:** The `reset_timer()` function cancels the active `after` loop using `root.after_cancel(p_timer)` and resets the UI state.
- **Assets:** `resize.py` uses PIL to scale the tomato image to fit the canvas dimensions.

## Watch Out / Pitfalls

| Mistake                     | Why It Happens                                                       | Fix                                                                                               |
| --------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| GUI freezes completely      | Using `time.sleep(1)` inside the Tkinter main loop                   | Use `root.after(1000, function)` to schedule events without blocking                              |
| Timer won't stop/reset      | Not keeping track of the `after` event ID                            | Save the return value of `root.after()` to a global variable and pass it to `root.after_cancel()` |
| Canvas image doesn't show   | `tk.PhotoImage` gets garbage collected if not assigned to a variable | Assign it: `self.img = tk.PhotoImage(...)`                                                        |
| Modifying Canvas text fails | Using `widget.config(text="...")` on Canvas items                    | Use `canvas.itemconfig(item_id, text="...")`                                                      |
