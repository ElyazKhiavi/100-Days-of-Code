# Day 42 — Intermediate HTML

## Core Concepts
- **HTML boilerplate** — `<!DOCTYPE html>`, `<html lang>`, `<meta charset>` + `<meta name="viewport">`, `<title>`.
- **Emmet abbreviations** — child `>`, sibling `+`, climb `^`, repeat `*n`, numbering `$` (with `@@` padding, `@n` start, `@-` reverse), grouping `()`, attributes `[]`, text `{}`, `loremN`.
- **`loading="lazy"`** — defers offscreen image loading; meaningful on image-heavy grids.
- **TMDB find-by-external-ID** — `GET /3/find/{imdb_id}?external_source=imdb_id` returns `movie_results[0].poster_path`; combined with the image base URL (`/t/p/w1280`).
- **MDN-first research protocol** — [MDN HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) before forums.

## Syntax / Key Commands
```html
<img src="poster.jpg" alt="descriptive alt" loading="lazy">
```

## Pitfalls
| Mistake | Why It Happens | Fix |
|---------|----------------|-----|
| API key in the query string | TMDB v3 auth style | Works, but keys in URLs reach server logs; TMDB v4 read tokens go in an `Authorization: Bearer` header |
| Hardcoding 18 `<article>` blocks by hand | One-off page | Templating from a data file arrives with Flask/Jinja (Days 54+); revisit then |
| Eager-loading a poster grid | Default `<img>` behavior | `loading="lazy"` on every grid image |
